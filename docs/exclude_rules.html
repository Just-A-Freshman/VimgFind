2. 特殊规则详解

特殊规则以 # 开头，后跟关键字 = 或 : 分隔的值。不与 gitignore 模式共用，其格式如下：

2
1
#<key> = <value>
2
#<key>:  <value>

3. 其他

  • 注释：不以特殊规则关键字开头的 # 行被视为注释，会被忽略。
  • 去重：相同的规则（不区分大小写）仅保留第一条。
  • 空行：完全忽略。
