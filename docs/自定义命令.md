>无论是常规模式还是批量模式，你所写的命令都是在操作系统的命令行环境中执行的（如 Windows 的 CMD/PowerShell，或 macOS/Linux 的 Shell）。当遇到需要执行复杂逻辑（如条件判断、循环嵌套）时，**强烈建议**编写外部脚本（如 .ps1, .sh, .py），通过本工具调用该脚本来执行。

# 1. 常规模式

## 1.1 基本介绍

当选中多个文件时，常规模式会对 N 个文件分别执行 N 次自定义命令。每次执行时，变量仅代表**当前这一个**文件。其主要适用于文件处理之间完全相互独立的情况，比如图片的批量上传、格式转换和压缩等。

**典型反例**：复制文件路径到剪切板。
由于复制操作通常会覆盖剪切板内容，如果在常规模式下循环执行，前一次复制的内容会被后一次覆盖，最终剪切板中只会留下最后一个文件的路径。

## 1.2 可用变量

| 变量      | 类型   | 描述                       |
| :-------- | :----- | :------------------------- |
| `{path}`  | String | 当前文件的绝对路径。       |
| `{dir}`   | String | 当前文件所在的目录。       |
| `{name}`  | String | 当前文件名（含后缀）。     |
| `{noext}` | String | 当前文件主名（不含后缀）。 |
| `{ext}`   | String | 当前文件后缀。             |

**安全机制**：
所有可用变量都会**被自动套上一层适合当前系统的引号**，并对引号内的特殊字符进行转义，以保证命令执行的稳定性。如果你非常确定你需要无引号的原始内容，可以使用修饰符：`{variable|raw}`（请注意：这可能导致包含空格的路径解析错误）。

**示例：**

```
> 命令：convert {path} {dir}/output_{noext}.jpg
> 实际运行：convert "C:/my image/1.png" "C:/my image/output_1.jpg"
>
```

# 2. 批量模式

## 2.1 基本介绍

批量模式下，命令只会被执行 **1 次**。选中的多个文件的信息会以列表的形式传递给程序，默认使用空格分隔。适用于文件打包、统一删除、或将文件列表作为参数传递给支持多输入的程序。



## 2.2 可用变量

| 变量          | 类型   | 描述                                                 |
| :------------ | :----- | :--------------------------------------------------- |
| `{paths}`     | List   | **所有**文件的路径列表（默认空格分隔）。             |
| `{first_dir}` | String | 列表中第一个文件所在的目录（常用于确定工作上下文）。 |
| `{count}`     | Number | 选中的文件总数。                                     |

**安全机制**：
与常规模式一致，`{paths}` 中的每个文件路径都会被**独立加引号**。你可以使用 `{paths|raw}` 强制去掉所有引号，但这极易导致命令解析错误，请谨慎使用。

**示例：**

```
> 命令：python script.py --input {paths} --work-dir {first_dir}
> 实际运行：python script.py --input "D:/source/1.png" "D:/source/2.png" --work-dir "D:/source"
>
```



## 2.3 指定分隔符

批量模式下，默认的 `{paths}` 变量使用空格作为分隔符。如果目标程序需要特定格式，可以通过修饰符指定分隔符。

**注意**：即使指定了分隔符，工具**仍会保留每个路径内部的引号**，以防止文件名中包含分隔符字符（例如文件名为 `A,1.jpg`）导致解析错乱。

**示例：**

1. `{paths|sep=\n}`：使用换行符进行分隔；
2. `{paths|sep=|}`：使用竖线 `|` 进行分隔（常用于 FFmpeg concat）；
3. `{paths|sep=,}`：使用逗号 `,` 进行分隔。



# 3. 用户注入变量

在某些场景下，命令执行时需要用户临时提供参数（如选择输出目录、输入版本号）。当系统检测到以下变量时，会在命令执行**前**弹出对话框，收集用户输入。**无论选中有多少个文件，这些变量只会触发一次输入，并应用到整个命令中。**

| 变量          | 类型    | 描述                                                         |
| :------------ | :------ | :----------------------------------------------------------- |
| `{ask_dir}`   | String  | 弹出文件夹选择窗口，返回所选文件夹的绝对路径。默认加引号并转义。<br />使用命令：`{ask_dir|raw}`强制去除引号。 |
| `{ask_file}`  | String  | 弹出单文件选择窗口，返回所选文件的绝对路径。默认加引号并转义。<br />使用命令：`{ask_file|raw}`强制去除引号。 |
| `{ask_files}` | List    | 弹出多文件选择窗口，返回所有文件的路径列表。与`{paths}`的定义完全类似，<br />详情请看#2.2 和 #2.3 |
| `{ask_input}` | String  | 弹出文本输入框，返回用户输入的字符串。                       |
| `{ask_int}`   | Integer | 弹出文本输入框，仅允许输入整数，非整数会报错并提前返回。     |
| `{ask_float}` | Float   | 弹出文本输入框，仅允许输入数字（支持小数），非小数会报错并提前返回。 |

**示例**：

```
> 命令：uploader.exe {paths} -dest {ask_dir}
> 执行流程：
> 1. 系统弹出文件夹选择框，用户选择 "D:/Backups"。
> 2. 系统执行：uploader.exe "file1.png" "file2.png" -dest "D:/Backups"
> 
```
