# 排除规则语法参考

排除规则采用与 `.gitignore` 兼容的语法，下面使用几个具体例子解释各种排除语法。

基于同一份图片目录，将每种语法规则与匹配结果一一对应，总结如下。

# 示例目录结构
```
Photos/                   ← 索引根目录
├── 人物/
│   ├── 张三.jpg
│   └── 李四.png
├── 风景/
│   ├── 日落.jpeg
│   ├── 日出.png
│   └── output/
│       └── 缩略图.jpg
├── 动物/
│   └── 猫.jpg
├── temp_1.jpg
├── temp_a.png
├── Photo_a.jpg
├── photo_a.jpg
├── 临时缓存.jpg
└── 重要备份.jpg
```


# 语法一览表（一表达式一结果）

| 表达式           | 匹配项（被排除/重新纳入）                      | 说明                                                         |
| ---------------- | ---------------------------------------------- | ------------------------------------------------------------ |
| `动物`           | `动物/` 目录及其内所有图片                     | **字面名称**匹配任意层级的同名文件或文件夹。                 |
| `*.png`          | `人物/李四.png`、`风景/日出.png`、`temp_a.png` | `*` 匹配任意多个非 `/` 字符。                                |
| `temp_?.jpg`     | `temp_1.jpg`                                   | `?` 匹配**单个**非 `/` 字符。                                |
| `[Pp]hoto_a.jpg` | `Photo_a.jpg`、`photo_a.jpg`                   | `[abc]` 字符集，匹配方括号内的任意一个字符。                 |
| `output/`        | `风景/output/` 目录及其内 `缩略图.jpg`         | 尾部 `/` 表示**只匹配目录**。                                |
| `/人物/`         | 仅根目录下的 `人物/` 目录                      | 前导 `/` 将匹配**锚定在根目录**，子目录中同名不受影响。      |
| `**/缩略图.jpg`  | `风景/output/缩略图.jpg`                       | `**` 匹配零个或多个目录层级。                                |
| `!风景/日出.png` | `风景/日出.png`（重新纳入）                    | `!` 取反，需配合前面的排除规则（如 `*.png`），按顺序后生效。 |
