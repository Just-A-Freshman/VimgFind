以下是排除规则的语法介绍。排除规则采用与 `.gitignore` 兼容的语法，并在此基础上扩展了文件大小、修改时间等**特殊规则**（以 `#` 开头）。

# 1. 标准模式示范

以下我们使用一个例子直接展示标准模式的语法：

```
Photos/                   ← 索引根目录
├── 人物/
│   ├── 张三.jpg
│   └── 李四.png
├── 风景/
│   ├── 日落.jpeg
│   ├── 日出.png
│   └── output/
│       └── 缩略图.jpg
├── 动物/
│   └── 猫.jpg
├── temp_1.jpg
├── temp_a.png
├── Photo_a.jpg
├── photo_a.jpg
├── 临时缓存.jpg
├── 重要备份.jpg
└── huge_scan.psd          # 30MB 大文件
```

表达式匹配表：

| 表达式 | 匹配项（被排除/重新纳入） | 说明 |
|--------|--------------------------|------|
| `动物` | `动物/` 目录及其内所有图片 | **字面名称**匹配任意层级的同名文件或文件夹。 |
| `*.png` | `人物/李四.png`、`风景/日出.png`、`temp_a.png` | `*` 匹配任意多个非 `/` 字符。 |
| `temp_?.jpg` | `temp_1.jpg` | `?` 匹配**单个**非 `/` 字符。 |
| `[Pp]hoto_a.jpg` | `Photo_a.jpg`、`photo_a.jpg` | `[abc]` 字符集，匹配方括号内的任意一个字符。 |
| `output/` | `风景/output/` 目录及其内 `缩略图.jpg` | 尾部 `/` 表示**只匹配目录**。 |
| `/人物/` | 仅根目录下的 `人物/` 目录 | 前导 `/` 将匹配**锚定在根目录**，子目录中同名不受影响。 |
| `**/缩略图.jpg` | `风景/output/缩略图.jpg` | `**` 匹配零个或多个目录层级。 |
| `!风景/日出.png` | `风景/日出.png`（重新纳入） | `!` 取反，需配合前面的排除规则（如 `*.png`），按顺序后生效。 |



# 2. 特殊规则详解
特殊规则以 `#` 开头，后跟关键字 `=` 或 `:` 分隔的值。**不与 gitignore 模式共用**，其格式如下：

```
#<key> = <value>
#<key>:  <value>
```

`key` 不区分大小写，`=` 和 `:` 均可。支持的关键字：

| 关键字 | 值格式 | 示例 | 效果 |
|--------|--------|------|------|
| `min_size` | `<数值> <单位>` | `#min_size: 100kb` | 排除**小于** 100KB 的文件 |
| `max_size` | `<数值> <单位>` | `#max_size=10mb` | 排除**大于** 10MB 的文件 |
| `min_modified` | `YYYY-MM-DD` 或 Unix 时间戳 | `#min_modified=2024-01-01` | 排除**修改时间早于** 2024-01-01 的文件 |
| `max_modified` | `YYYY-MM-DD` 或 Unix 时间戳 | `#max_modified=1704067200` | 排除**修改时间晚于** 指定时间的文件 |

其中，数值的单位参考表：

| 单位 | 含义 | 示例 |
|------|------|------|
| `b` | 字节（默认，可省略） | `500b` 或 `500` |
| `kb` | 千字节 (1024 B) | `100kb`、`1.5kb` |
| `mb` | 兆字节 (1024² B) | `10mb`、`0.5mb` |

# 3. 其他
- **注释**：不以特殊规则关键字开头的 `#` 行被视为注释，会被忽略。
- **去重**：相同的规则（不区分大小写）仅保留第一条。
- **空行**：完全忽略。
